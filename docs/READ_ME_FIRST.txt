PASTEL VALORANT RANK OVERLAY

Thank you for your purchase!

1. Open START_HERE.pdf for the full illustrated setup guide.
2. Generate your free HenrikDev API key:
   https://api.henrikdev.xyz/dashboard/
3. Open the overlay setup page:
   https://pastel-valorant-rank-widget.vercel.app/
4. Enter your API key and Riot ID in Name#TAG format.
5. Choose PC or Console. Under Theme, select Pastel or Halloween.
   For Pastel, choose Rose, Lavender, Sky, Mint, or Peach.
6. Copy the generated widget URL.
7. Add it to OBS, Meld, or Streamlabs as a Browser Source.
8. Set the source to 1952 x 1104, then scale it down in your scene.

UPDATING AN EXISTING OVERLAY: Open the setup page above, enter your existing
API key and Riot ID, select your theme, and copy a new widget URL. Replace the
URL in your existing Browser Source and refresh it. If the setup page has no
Theme selector, you are using the older site; use the link above.

IMPORTANT: Keep your API key and complete widget URL private. Do not send the part of the URL after # when asking for support.
